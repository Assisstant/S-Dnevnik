СОДРЖИНА НА ОВОЈ ФОЛДЕР:
─────────────────────────────────────────────────────────────
  S-Dnevnik_v7.html          ← Главна апликација (отвори во Chrome)
  document_factory_v7.py     ← Напреден генератор на документи
  compact_factory.py         ← Едноставен шаблон генератор
  run_config.py              ← Го чита gen_config.json и генерира
  launcher.py                ← GUI лансер (за tkinter)
  setup.py                   ← Автоматска инсталација
  template.docx              ← Пример шаблон за compact_factory
  e_dnevnik_unified_state_v7.json ← Пример податоци (заменете со свои)
  LAUNCHER.bat               ← Двоен-клик за стартување
  SETUP.bat                  ← Двоен-клик за инсталација (еднаш)

═══════════════════════════════════════════════════════════════
  ЧЕКОР 1: ИНСТАЛАЦИЈА (само еднаш)
═══════════════════════════════════════════════════════════════

  1. Инсталирајте Python од https://www.python.org/downloads/
     ВАЖНО: Означете "Add Python to PATH" при инсталација!

  2. Двоен-клик на SETUP.bat
     → Ова креира виртуелна околина и инсталира python-docx

  3. Ако Windows прикаже "Windows protected your PC":
     → Кликнете "More info" → "Run anyway"
     → Десен-клик на SETUP.bat → Properties → Unblock → OK
     (Ова е потребно само еднаш!)


═══════════════════════════════════════════════════════════════
  ЧЕКОР 2: ПОДГОТОВКА НА ПОДАТОЦИ
═══════════════════════════════════════════════════════════════

  1. Отворете S-Dnevnik_v7.html во Chrome/Firefox

  2. Внесете ученици во табот "Ученици"
     или импортирајте JSON во табот "Податоци"

  3. Одете во табот "📄 Генератор"


═══════════════════════════════════════════════════════════════
  ЧЕКОР 3: ГЕНЕРИРАЊЕ НА ДОКУМЕНТИ
═══════════════════════════════════════════════════════════════

  Во табот Генератор:

  1. Изберете тип на документ (Досие, Родителски средби, итн.)
  2. Изберете ученици (сите или еден)
  3. Прилагодете ги поставките (фонт, терапевт, итн.)
  4. Кликнете "📥 Експорт JSON за генератор"
     → Зачувајте го во ОВОЈ фолдер
  5. Кликнете "💾 Зачувај конфиг → LAUNCHER.bat"
     → Зачувајте го gen_config.json во ОВОЈ фолдер

  6. Двоен-клик на LAUNCHER.bat
     → Автоматски ги генерира документите!
     → Резултатот е во OUT/ фолдерот


═══════════════════════════════════════════════════════════════
  ЗА ШАБЛОНОТ (template.docx)
═══════════════════════════════════════════════════════════════

  template.docx е обичен Word документ со плејсхолдери:

  {{firstName}}     ← Име на ученикот
  {{lastName}}      ← Презиме
  {{grade}}         ← Одделение
  {{birthDate}}     ← Датум на раѓање
  {{findings}}      ← Наоди
  {{opinion}}       ← Мислење
  {{attachments}}   ← Прилози

  Отворете template.docx во Word/LibreOffice, 
  додајте го заглавјето на вашата институција,
  форматирајте по желба, и зачувајте.


═══════════════════════════════════════════════════════════════
  ПРОБЛЕМИ? 
═══════════════════════════════════════════════════════════════

  П: Windows вели "virus detected" или "protected your PC"
  О: Десен-клик на .bat → Properties → Unblock → OK
     Ова е потребно само еднаш за секој .bat фајл.

  П: "Python is not recognized"
  О: Реинсталирајте Python и означете "Add Python to PATH"

  П: "ModuleNotFoundError: No module named 'docx'"
  О: Двоен-клик на SETUP.bat за да се инсталира python-docx

  П: "document_factory_v7.py not found"  
  О: Сите фајлови мора да бидат во ИСТИОТ фолдер!
     Не ги ставајте во подфолдери.
